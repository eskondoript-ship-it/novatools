Pricing

Everything is free. Here is why that holds.

Free tools usually mean a trial, a watermark, or a wait. None of those apply here, and the reason is structural rather than generous.

What it costs to run this site

NovaTools is a static file on a content delivery network. There is no application server, no database, no queue and no GPU. A visitor who uses fifty tools costs exactly the same to serve as one who reads the front page and leaves, because all fifty ran on their own machine.

That is the whole economic argument. A site whose marginal cost per user is approximately zero does not need to charge per user. Sites that do charge generally have a real per-request cost — a model API, a rendering farm, storage — and this one deliberately avoids all three.

How it is funded

Advertising, and nothing else at present. Ad units sit between sections of a page and above the footer. They are never placed inside a tool panel, never interrupt something you are in the middle of, and blocking them does not disable anything — the tools are the same code either way.

If you would rather support the site than see the ads, the most valuable thing you can do costs nothing: link to a tool that helped you. Search traffic is what keeps this viable.

Will there be a paid tier?

Possibly, and only for things that genuinely cost money to run. The honest position today is that none of it exists:

  • Tools that need a model API — image generation, transcription, voice work. These have a real cost per request, so if they arrive they will have to be paid for somehow. They are on the roadmap, clearly marked as not built.
  • An ad-free option. Plausible in principle. It does not exist, and there is no waiting list to join.
  • An API. Frequently requested for the size and limit tables. Would need a server. Not built.

What will not happen: taking a tool that works today and putting it behind a paywall tomorrow. The 2,119 tools currently on the site stay free.

Sponsorship and affiliate links

There are none. If that changes, a sponsored tool or a commission-paying link will be labelled on the page it appears on — not in a policy page nobody reads. That commitment is in the Disclaimer.
