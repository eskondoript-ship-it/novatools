Send a message

How this form behaves If a form endpoint has been configured it posts your message directly. If not, it opens your own mail client with the message filled in, so you can see exactly what is being sent and to whom. It will never show you a confirmation for something that was not actually sent.

What is most useful to report

  • A number that is wrong. Which tool, what it said, and what the platform's own documentation says. These get fixed fastest because the fix is one line in a table.
  • A tool that fails in your browser. Which browser and version, and what you had entered. Image tools in particular depend on encoder behaviour that differs between browsers.
  • A tool that should exist. Especially if it is a single well-defined job. The catalogue grows by adding rows to a table, so a good suggestion is cheap to act on.

Privacy requests

We hold no personal data about visitors, so there is nothing to export or delete on our side — see the Privacy Policy for why. Requests about data held by an advertising or analytics provider have to go to that provider, as they are the controller of it. If you are not sure which applies, ask here and we will point you to the right place.
